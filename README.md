# 🚗 车讯通 - 汽车行业周报

## 简介
车讯通是一款汽车行业资讯聚合应用，每周自动收集整理汽车行业最新动态，包括行业政策、新车发布、企业新闻、技术趋势和市场热点。

## 安装
已在桌面创建快捷方式：
- **车讯通.webloc** - Safari 快捷方式
- **车讯通.app.command** - 双击打开应用

## 功能特点

### 📊 五大分类
- 🏛️ **行业动态** - 政策法规、行业报告
- 🚘 **新车发布** - 新车型上市、预售信息
- 🏢 **企业新闻** - 车企财报、战略合作
- 🔬 **技术趋势** - 新能源、智能驾驶
- 📈 **市场热点** - 销量排行、价格变动

### 🔗 真实数据源
- 每条资讯都附带**可点击的来源链接**
- 数据来源：新浪汽车、IT之家、东方财富、彭博社等权威媒体
- 数据更新时间：2026年4月20日

### 🔄 数据更新
- **自动更新**：每周一上午9点自动刷新数据
- **手动更新**：点击应用中的"刷新数据"按钮
- 数据源位置：`~/.openclaw/workspace/车讯通/data.js`

## 使用说明

### 打开应用
1. 双击桌面的 **"车讯通.webloc"** 或 **"车讯通.app.command"**
2. 应用将在默认浏览器中打开

### 筛选资讯
- 点击顶部分类标签查看不同类别资讯
- 点击"全部"查看所有资讯

### 查看详情
- 点击每条资讯右下角的"查看原文 →"可跳转到原始新闻页面
- 资讯按时间排序，最新的在最前面

### 刷新数据
- 点击"🔄 刷新数据"按钮获取最新资讯
- 或每周一自动更新

更新机制

建议固定每周一更新一次 `assets/data.js`，新资料直接追加进现有 `records`，不要覆盖旧资料。这样所有历史资料会一直保留，前端通过时间筛选自动区分不同周的数据。

推荐流程

1. 周一采集当周新资料

2. 追加进对应行业 `records`

3. 同步更新 `meta.updatedAt` 与 `meta.version`

4. 如需留档，再复制一份当周完整站点到独立归档目录

历史保留方式

日常版本：继续维护当前主站，保留全年累计资料。

归档版本：按周复制为 `archive/2026-06-29/` 这类目录，形成周版本快照。

统一公开链接建议

这套页面是纯静态站点，最适合发布到支持静态托管的平台。发布后你会得到一个统一网址，其他人打开即可访问。

最省事方案

1. GitHub Pages

2. Cloudflare Pages

3. Netlify
